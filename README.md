Orbit Guard — defend the last garden planet from the asteroid storm. Aim the orbital cannon with the mouse, hold click to fire lasers, drop shockwave bombs with Space, and hold the line through ten escalating waves of asteroids, drones, brutes and comets. Survive wave 10 and the planet is saved; let the hull reach zero and it falls. Score chains into combos, waves pay bonuses, and every run is a fresh storm.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
